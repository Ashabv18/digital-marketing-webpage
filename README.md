# Kaala Mithra — Digital Marketing webpage

This folder contains a complete, responsive Digital Marketing service webpage and its editable source project.

## Open the webpage

Open `index.html` in a modern browser. The built page is self-contained, with its CSS, fonts, logo and marketing imagery embedded.

## Included files

- `index.html` — ready-to-view standalone webpage
- `index.src.html` — editable HTML source
- `theme.css` and `fonts.css` — styling and embedded fonts
- `assets/` — brand logo and original illustrative digital-marketing images
- `build.py` — rebuilds the standalone page
- `qa.py` — static acceptance checks

## Rebuild and check

From this directory, run:

```bash
python3 build.py
python3 qa.py
```

The build script uses Pillow (`PIL`). Install it with `python3 -m pip install Pillow` if needed.
